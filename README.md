# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi

Character Manager adalah program Java sederhana untuk mengelola data karakter. Program ini menggunakan konsep Object-Oriented Programming (OOP) seperti class, constructor, encapsulation, getter/setter, enum, dan method.

Pada project ini juga terdapat fitur level up, mana, validasi mana, serta pengecekan apakah character masih hidup menggunakan method `isAlive()`.
